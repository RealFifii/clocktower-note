# 钟楼手记

玩《血染钟楼》时，帮你记下每个人的说法、角色猜测和每天每夜的信息，方便自己回看和推理。

## 直接开始使用

[打开钟楼手记](https://realfifii.github.io/clocktower-note/)

电脑、手机都可以使用。iPhone 请用 Safari 打开网址，不要在“文件”App 中预览 HTML。可以通过 Safari 分享菜单添加到主屏幕。

## 开局与记录

1. 在“开局设置”选择剧本，点击“使用此剧本”，再选择人数和自己的座位。
2. 在“座位与角色声明”填写姓名、角色声明、角色猜测、阵营倾向、存活状态和笔记。
3. 在“每日 / 每夜信息”填写信息后点击“记录信息”。每个阶段可记多条，点击“下一阶段”继续。
4. 在“我的推理笔记”记录自己的思路和疑点。

“座位身份汇总”会自动显示声明、猜测或未知，声明不代表真实身份。“总结信息”会整理本局记录，点击“一键复制”即可粘贴给 AI 分析。

## 添加或修改剧本

进入“管理剧本”，新增剧本，或选择已有剧本并点击“载入所选剧本”。填写名称，在校对框粘贴角色名，每行一个，不带技能说明，再点“保存剧本与角色”。照片可以先发给 AI 提取，再复制到这里。

返回记录页面，选择剧本并点击“使用此剧本”，即可点选角色猜测。

## 新剧本只需更新剧本文件

网页是 `index.html`，共享剧本库单独保存在 `scripts.js`。新增或修改剧本时，只需更新仓库中的 `scripts.js`，不用修改 HTML。

网页保存只会先保存到当前浏览器。想分享给其他设备：

1. 在管理页面点击“导出共享剧本库”。
2. 将下载的 `scripts.js` 上传到 GitHub 仓库，替换同名文件并保存更改。
3. 等待网站发布完成，在其他设备打开网页，或点“检查共享剧本更新”。

目前有风雅集、懦夫救星、双重疯狂、午夜俱乐部、桃之夭夭、惜墨如金六套剧本。

如果本机有不同修改，页面会保留它们。确定使用仓库内容时，先导出需要保留的修改，再点“采用仓库版本”。更新不会改变正在进行的这一局，需重新选择并使用剧本才会应用新版角色列表。

## 复制给 AI 分析

在“总结信息”中点击“更新总结”，确认内容已更新后点击“一键复制”，再粘贴给 AI 分析，或粘贴到自己的文档中留存。每日／每夜的信息需先点击“记录信息”才会进入总结。
## 我的记录保存在哪里？

游戏记录自动保存在当前设备的当前浏览器，不会自动同步到其他设备。清除网站数据可能丢失记录，重要内容请及时复制总结信息留存。复制的文字供阅读和分析，不能直接导入恢复页面。

新开一局前请先复制旧局总结；保存过的剧本会保留。共享剧本库不包含游戏笔记，请不要把个人分析记录上传到公开仓库。

打开网站和获取剧本更新需要网络，目前没有专门的离线缓存功能。

## 想自己发布一份？

将项目文件上传到 GitHub 仓库，在 Settings → Pages 中选择从 `main` 分支根目录发布。保存并等待部署完成，就会得到网页链接。免费账户使用 Pages 时，仓库需保持公开。

[GitHub Pages 官方发布说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

本地打开时，请把 index.html 和 scripts.js 放在同一个文件夹，再用电脑浏览器打开 index.html。修改本地 scripts.js 后刷新页面。
