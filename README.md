# 钟楼手记

玩《血染钟楼》时，帮你把每个人的说法、角色猜测和每天每夜的信息记下来，方便自己回看和推理。

这是一个玩家用的记录本。你可以随时修改猜测，也可以导出记录交给 AI 分析。

## 直接开始使用

[打开钟楼手记](https://realfifii.github.io/clocktower-note/)

## 开局怎么设置？

1. 在“开局设置”中选择这次玩的剧本，点击“使用此剧本”。
2. 选择玩家人数和自己的座位。
3. 在“座位与角色声明”中填写玩家名字、角色声明，以及你对他们身份的猜测。

目前提供六套剧本：风雅集、懦夫救星、双重疯狂、午夜俱乐部、桃之夭夭、惜墨如金。你也可以添加自己的剧本。

## 游戏中怎么记录？

- **座位与角色声明**：记下每个玩家说自己是什么角色，在角色选项里选择你的猜测，并补充存活状态、阵营倾向和备注。
- **座位身份汇总**：自动整理各座位的身份说法；有声明时优先显示声明，没有声明时显示猜测，都没有就显示未知。这里不用手动填写，声明也不代表真实身份。
- **每日 / 每夜信息**：选好阶段和信息来源，写完后点击“记录信息”。同一天或同一夜可以添加多条；点击“下一阶段”继续，之前的信息会保留。
- **我的推理笔记**：记录自己的思路、疑点和接下来想问的问题。

需要开始另一局时，先导出想保留的记录，再点击“新开一局”。保存过的剧本会保留。

## 怎么添加或修改剧本？

点击“管理剧本”，进入单独的管理页面。

1. 新剧本点击“新增剧本”；修改已有剧本时，选择它并点击“载入所选剧本”。
2. 填写或修改剧本名称。
3. 在“校对角色名称”中粘贴角色列表，**每行一个角色名，不要带技能说明**。可以先把照片发给 AI 提取，再复制到这里。
4. 点击“保存剧本与角色”。
5. 点击“返回记录”，选择该剧本并点击“使用此剧本”，就能在座位记录中点选角色猜测。

## 手机和电脑能看到同样的剧本吗？

可以，各设备会读取网站发布的同一份剧本库。不过，**在网页里保存剧本，只会先保存在当前设备上**，还需要下面这一步才能分享给其他设备：

1. 在“管理剧本”中点击“导出共享剧本库”。
2. 将下载的 `scripts.json` 上传到 GitHub 仓库，替换原来的同名文件，并保存更改。
3. 等待网站更新后，在其他设备打开网页，或点击“检查共享剧本更新”。

如果设备上有尚未上传的不同修改，页面会先保留它们。确定要使用网站上的版本时，可以点击“采用仓库版本”；覆盖前建议先导出一份。

更新剧本库不会改变正在进行的这一局。想使用更新后的角色列表，需要重新选择剧本并点击“使用此剧本”。

## 怎么让 AI 帮我分析？

点击“导出分析记录”，把下载的文件上传给 AI 即可。文件会整理本局角色列表、座位声明与猜测、每日每夜信息和推理笔记。

这个文件也能用来恢复记录：在钟楼手记中点击“导入记录”，选择之前导出的文件。导入会替换当前记录及剧本库，请先保存需要保留的内容。

## 我的记录保存在哪里？

日常修改会自动保存在**当前设备的当前浏览器**里。电脑和手机的游戏记录不会自动同步，换浏览器也不会自动带过去。

重要记录建议及时“导出分析记录”。清除浏览器网站数据可能会丢失本机记录；从本地文件换到网页时，也需要导出、导入来搬过去。

“导出共享剧本库”只包含剧本名称和角色，不包含你的游戏笔记。请不要把个人分析记录上传到公开仓库。
